# CAS - Laboratorio 02

## Gestión de requerimientos y control de cambios

Este repositorio contiene la evidencia de seguimiento utilizada para el Laboratorio 02 de Calidad de Software. El trabajo toma cinco solicitudes de cambio registradas también en i-doit y las administra mediante GitHub Issues para mantener trazabilidad, responsable, estado y criterios de aceptación.

### Solicitudes de cambio

| ID | Cambio | Requerimiento de origen | Prioridad | Estado |
|---|---|---|---|---|
| LAB2-CHG-001 | Validación de documento único | RF-01 Registro de estudiantes | Alta | En desarrollo |
| LAB2-CHG-002 | Control de exceso de vacantes | RF-02 Gestión de matrícula | Crítica | En revisión |
| LAB2-CHG-003 | Bloqueo temporal de cuenta | RF-04 Control de acceso | Alta | En pruebas |
| LAB2-CHG-004 | Filtros avanzados de reportes | RF-07 Generación de reportes | Media | Pendiente |
| LAB2-CHG-005 | Auditoría ampliada de operaciones | RF-08 Auditoría y logs | Crítica | Cerrado |

### Flujo utilizado

`Registrado -> Análisis -> Revisión CCB -> Implementación -> Verificación -> Cierre / Nueva línea base`

Los detalles de cada RFC se documentan en GitHub Issues y los documentos complementarios se encuentran en la carpeta `docs/`.
