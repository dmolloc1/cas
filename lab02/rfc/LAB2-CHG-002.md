# LAB2-CHG-002 - Control de exceso de vacantes

Origen: RF-012, RF-018, RN-04
Prioridad: Alta
Estado: En revisión

La matrícula se bloquea al alcanzar el límite de una sección y cualquier excepción debe conservar motivo, autorización y responsable.

Criterios principales: validar disponibilidad, registrar excepción autorizada y actualizar el número de vacantes después de cada matrícula válida.
