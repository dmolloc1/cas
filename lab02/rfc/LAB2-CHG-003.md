# LAB2-CHG-003 - Bloqueo temporal de cuenta

Origen: RF-031, RN-10, RNF-005
Prioridad: Alta
Estado: En pruebas

Después de cinco intentos fallidos consecutivos la cuenta queda bloqueada temporalmente y el evento se registra para auditoría.

Criterios principales: bloqueo al quinto intento, impedir acceso durante el bloqueo, registrar fecha y usuario y permitir recuperación autorizada.
